# Source-only BN running-statistic write experiment

This Houston13→Houston18 development experiment tests whether auxiliary target/augmentation forwards corrupt the CE-DCRN's inference-time BN state. It does **not** introduce a new model or claim a publishable method. Input is the original raw HSI cube in both arms. Baseline: completed `investigations/ilda_input_ablation_v1/raw_{seed}`. Intervention: the same six train-mode forward passes, CE loss, gradients, augmentation, 180/class source split, 53,200 ordered target centers, 7×7 patches, batch 32, 38 updates/epoch, official SGD schedule, and 100 epochs. After the supervised original-source forward, snapshot the seven BN running-mean/variance/counter triples; let the five auxiliary forwards run normally; restore the snapshot after backward and before the optimizer step. Thus only the original labeled-source pass contributes to inference BN buffers. Training-mode batch statistics and all parameter gradients should be unchanged. The first smoke attempt restored before backward and failed PyTorch's in-place version check before any optimizer step; the recovery point was corrected before formal training.

Seeds: 202601, 202602, 202603, paired on the same GPU indices as the raw baseline (5, 3, 2). First run a one-epoch seed-202601 smoke. Require identical source/target center arrays, 38 steps, input hashes, CPU RNG hashes, source-logit/gradient/parameter hashes at every step, and different BN buffer hashes. If parameter hashes diverge, investigate before formal runs.

Primary checkpoint: earliest strict source-val-best, matching the locked protocol. Secondary mechanistic readout: epoch 100 of both arms; because parameters should be identical there, its paired target difference isolates BN buffers without checkpoint-selection effects. Freeze all 53,184 target predictions and hashes before post-hoc GT scoring. Official OA is correct/53,200; AA, Kappa, and per-class recall use the 53,184 evaluated positions. Report each seed and mean ± sample SD (ddof=1) for source-val accuracy, OA, AA, Kappa, weak classes, selected epoch, and BN buffer/parameter equality. No target metric is used to tune the BN rule or select a checkpoint.

Interpretation gates: source-val improvement without target improvement means source BN repair alone is insufficient for transfer; a target gain only at source-val-best but not at fixed epoch 100 could be checkpoint-selection mediated; a paired target gain at both readouts supports a BN-state mechanism but still requires a separate scene and a method-level innovation.
