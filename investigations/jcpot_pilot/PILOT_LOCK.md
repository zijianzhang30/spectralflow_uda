# Single-source JCPOT frozen-feature pilot

This is a diagnostic adaptation of Redko et al. (AISTATS 2019), not a claim to reproduce their multi-source setting. It uses the already-frozen source-val-best CE DCRN feature caches for seeds 202601/202602/202603. For each seed, L2-normalize the 1,260 labeled source-train features and the **first 8,192** official-order unlabeled target features. Do not inspect target GT when selecting this prefix or fitting JCPOT.

Call POT 0.9.3 `ot.bregman.jcpot_barycenter` at the complete predetermined regularization grid `[0.1, 0.2]`, `numItermax=200`, `stopThr=1e-6`, `log=True`. **POT 0.9.3 has a K=1 list-unpacking bug:** it expands the sole source array into rows before backend checking. Pass two identical copies of the same source features and labels as a compatibility workaround, and assert their output couplings agree. This is still one distinct source, duplicated, and must not be described as a multi-source experiment. Save each estimated seven-class proportion and full coupling before opening target GT; also save the class posterior induced by each target coupling column. Record iteration count, final change and both marginal residuals. Fail if any probability, coupling or proportion is non-finite or negative. Do not select a regularization strength from Houston18 GT.

Post-hoc, on the **same 8,192 target positions**, compare DCRN mean soft probability, HyperSIGMA mean soft probability, both JCPOT proportions, and actual class proportions. Report L1 distance and class-7 proportion error; these labels are never used to fit JCPOT. Compare JCPOT coupling-derived target predictions against the same-prefix DCRN and HyperSIGMA predictions as diagnostic OA, AA, Kappa and per-class recall. These pilot classification metrics use `correct/8192` and are **not official full-scene OA**. No full-scene KL correction or Flow follows from this pilot alone.

Before GT audit, run the already-existing soft-KL objective at **lambda=1** on this same 8,192-row DCRN probability matrix, separately using the same-prefix HyperSIGMA mean probability and each JCPOT prior. Lambda=1 is an exploratory value from the already-inspected Houston18 curve; it is fixed here only to compare priors under identical correction strength, not to validate lambda or make an independent claim. Save all three corrected arrays and solver records before GT audit. Compare their pilot classification and class-7 metrics post-hoc, with no target-selected winner.

The cost is squared Euclidean distance between unit-normalized 288-d DCRN features, equivalent to twice cosine distance. Since the class-conditional shift may be large, a JCPOT prior can fail even if its optimization converges. Report numerical convergence and semantic quality separately.
