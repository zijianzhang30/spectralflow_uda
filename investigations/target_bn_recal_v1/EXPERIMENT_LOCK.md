# Frozen-weight target-only BN recalibration diagnostic

Date: 2026-09-27. Proposed after source-only BN recalibration on labeled source training patches restored nearly all source-validation class recalls without changing weights. This is an exploratory Houston18 development test. No Houston18 target class label is used to design the calibration rule or select a checkpoint.

For each seed 202601/202602/202603 and each source-val-best checkpoint of **A (CE DCRN)** and **SHIFT (SceneShift DCRN)**, use the same official ILDA target cube and already frozen 53,200 GT>0 target center positions/order. Load the checkpoint; perform exactly **one** sequential pass over all 53,200 unlabeled target patches, 7×7, batch 32, `shuffle=False`, `drop_last=False`, `num_workers=0`, with the model in `train()` and `torch.inference_mode()`. This updates only the existing BatchNorm running mean/variance and batch counters with the model's native momentum 0.1. There are no optimizer steps, gradients, pseudo-labels, loss terms, added parameters, or use of source/target labels in calibration. Do not reset BN buffers before the pass. Verify all trainable parameter tensors are bitwise unchanged and BN buffers have changed. Save the resulting model state and its hash.

Then switch to `eval()` and run the unchanged official target inference on the same center order with `batch_size=32`, `drop_last=True`, yielding 53,184 predictions. Save raw probabilities and, as a separate fixed readout, apply the same previously locked HyperSIGMA prior and soft-KL strength 1. Save all six full-scene raw/corrected probability arrays and hashes **before** opening target GT. The reference comparators are the exact original A and SHIFT source-val-best checkpoints, without BN recalibration, with raw and same fixed-prior readouts. Score OA as `correct/53200`, AA/Kappa on actual 53,184 predictions; report each seed, all per-class recalls, source class collapse, and change in target performance. No coefficient or checkpoint is selected from target GT.

A gain would identify domain-specific BN statistics as a practical bottleneck but **would not itself be a top-conference algorithm**; AdaBN-style recalibration is a known baseline. A subsequent paper method would need to explain/solve how source and target class structure remain stable during domain-specific normalization, outperform this baseline, and validate unchanged rules on an untouched PaviaU→PaviaC or Shanghai→Hangzhou scene.
