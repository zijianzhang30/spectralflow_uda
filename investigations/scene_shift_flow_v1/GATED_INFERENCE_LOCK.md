# Support-matched inference diagnostic

This diagnostic was defined **after** the ungated Flow target scores were inspected, so it is exploratory and cannot be an independent Houston18 selection. It tests a concrete train/inference mismatch without retraining or tuning: the existing Flow's classwise OT training admitted target candidates only at corrected `max(q)>=0.95`, but the first evaluation applied the field to every target. Use that identical fixed 0.95 support condition on the saved full-53,200 corrected target probability matrix. For the first 53,184 official test positions, use the saved Flow-transported raw classifier probability only when that condition holds; otherwise keep the original frozen SceneShift raw probability. Apply the **same** pre-existing HyperSIGMA-prior soft-KL `lambda=1` to the hybrid probability matrix. Save the gated raw and corrected predictions, mask count, all input hashes and solver residual before any target-GT scoring of this new diagnostic.

Compare original SHIFT, ungated Flow, and support-matched Flow at raw and corrected inference. No new gate, alpha, solver steps, Flow checkpoint, pseudo-label CE, source/target label values or validation rule may be chosen from Houston18 GT. If the gated version still fails, investigate whether source endpoints are classifier-consistent before changing Flow architecture.
