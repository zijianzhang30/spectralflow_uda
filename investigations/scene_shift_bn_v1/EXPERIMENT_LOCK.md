# SceneShift auxiliary BN-buffer isolation

This experiment was proposed after the completed SceneShift and Flow Houston18 diagnostics; it is **exploratory**, not independent validation. Compare the existing SHIFT method to SHIFT_BN at the same seeds 202601/202602/202603. The **only** intervention is auxiliary BN buffer handling. SHIFT_BN performs the same seventh shifted-source forward in `train` mode, so it uses current shifted-batch statistics and retains the same CE gradient and dropout/RNG semantics. **After backward but before optimizer step**, it restores each BN module's `running_mean`, `running_var` and `num_batches_tracked` to its pre-auxiliary state. The six official passes and their BN updates are unchanged. No BN module is switched to `eval` for the auxiliary pass. The first technical smoke tried restoring before backward and failed PyTorch's autograd version check; this was fixed before any formal training or new target-GT scoring.

Retain the same post-ILDA full-cube source→target SceneShift statistics, alpha 0.7, multiplicative/smoothed noise, clamp, `CE_s+0.5 CE_shift`, official Houston13→Houston18 split (180/class), target GT>0 center order, 7×7 patch, batch32, 38 updates/epoch, SGD/LR/decay/momentum, 100 epochs and earliest source-val-best checkpoint. The SceneShift random generator remains independent. No target class label, pseudo-label, HyperSIGMA gradient, OT or Flow is used in training.

Run a five-epoch technical smoke: compare 190 source/target input and CPU RNG hashes with SHIFT; CUDA RNG hashes with SHIFT; verify first-step source/shift CE and parameter gradient hashes are identical, while BN buffers differ. Any autograd error or mismatch in the first-step gradient invalidates this implementation. No target-GT smoke scoring. If sound, train all three seeds for 100 epochs, freeze target raw probability matrices, then apply the same pre-existing HyperSIGMA soft-KL `lambda=1` as a secondary measure before reading target GT. Report official OA, AA, Kappa, all class recalls and mass for SHIFT versus SHIFT_BN, with raw results visible. A positive result needs new-seed/scene confirmation and cannot be attributed to Flow.

Before formal training, also record each existing SHIFT model's source-val-best epoch (11/14/21) and retain a `paired_shift_epoch.pth` for SHIFT_BN at that same epoch. This read-only checkpoint save does not change training. It permits a same-epoch post-hoc evaluation to distinguish BN-buffer effects from changes in source-val checkpoint choice; it is not a target-selected model.
