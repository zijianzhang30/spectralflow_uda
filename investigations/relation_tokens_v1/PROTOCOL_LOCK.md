# Houston relation-token pilot: fixed before target scoring

This is a **one-seed development pilot**, not a new-method result. Houston18 target GT has already informed earlier research; it will not choose this pilot's architecture, checkpoint, or hyperparameters.

- Seed 1341; Houston13→Houston18; exactly the official MLUDA source/target centers and source-only validation split; official ILDA input; 7×7 patches; batch 32; 100 epochs; 38 steps/epoch; same epoch-wise SGD schedule, optimizer reset, and full MLUDA objective as `official_aligned/full_mluda.py`. Select both source-validation-best and fixed epoch-100 checkpoints for readout; fixed epoch 100 is primary paired comparison.
- Replace only `DSANSS.feature_layers.atten` with a wrapper: four learned 288-dimensional relation tokens query the 32 source and 32 target pooled feature vectors with 4-head attention; source and target vectors then separately query the resulting relation tokens and receive sigmoid-gated residual updates. The original MLUDA `CrossAttention` remains after this update. Domain type embeddings are learned. No HyperSIGMA, OT, Flow, extra loss, or target labels enter training.
- Initialize both gate output layers to zero weights and bias −2; all other new layers use PyTorch defaults. The exact saved source/target center arrays are checked against the baseline. The RNG stream used for data ordering is restored after new module initialization, so the additional parameters do not by themselves change subsequent sampling RNG.
- First run a 1-epoch smoke for finite forward/backward gradients and matching center arrays. Then run seed 1341 for 100 epochs on an available GPU. Freeze target probabilities, checkpoint hashes, selection metadata, and a source-batch-replacement sensitivity probe before reading Houston18 GT for this pilot. Compare OA, AA, Kappa, all class recalls, and cost to the paired official MLUDA checkpoint. Do not tune token count, gate bias, checkpoint, or training loss on the target metric.
- A positive pilot only justifies expansion to paired seeds and independent scenes. A token model that changes predictions without improving accuracy, or improves only one Houston seed, is not a paper result. A capacity-matched attention control is required before any token-specific claim.
