# Frozen correspondence audit

This audit uses the existing 202601/202602/202603 `soft_*/probabilities_before_gt.npz` files and the entire predeclared nine-point soft-KL grid. It does not train, select a lambda, alter probabilities, or use target labels to construct a method. Houston18 GT enters only post-hoc diagnostics. The existing 0.8 gate and first 200 official target batches remain fixed.

For each true class, decompose evaluated pixels into (i) wrong argmax, (ii) correct argmax but below the 0.8 gate, and (iii) correct argmax above the gate. Report all three fractions of the true class support and verify they sum to one. Also report the mean probability assigned to the true class, the classwise expected purity if each target distributes its mass over all source classes according to `q`, and overall expected correctness `mean_i q[i,y_i]`. These soft quantities are diagnostic expectations, not observed Flow performance.

For the first 200 target batches, use the same sequential, cycling source-train batches. For each source class present, compare the old hard rule (only targets with argmax class and confidence at least 0.8, weighted by `q_c`) with a purely soft mass allocation (all 32 target positions weighted by `q_c`). Conditional class purity is the fraction of that mass belonging to the correct true class. Average per enabled source-class batch with the existing `score_pairs` 32-unit weighting. Report enabled-batch counts and classwise as well as overall purity; do not compare purity without exposure/coverage. Verify the hard calculation reproduces the prior Sinkhorn expected-purity audit within numerical tolerance.

The old per-class OT pairs contain source points of a single known class. Since Sinkhorn fixes the target marginal to normalized `q_c`, its expected semantic pair purity is mathematically this weighted target-label purity, independent of the feature transport cost when marginals are met. This audit checks that implication; it does not claim to evaluate feature geometry or actual model accuracy after Flow.
