# Official-protocol source SceneShift pilot

Motivation: historical positive SceneShift records and recent negative variants differ in CE weighting, auxiliary BN semantics, and augmentation. This experiment treats the historical **composite source-view recipe** as one intervention against the existing CE-only A control. It does not attribute any gain to one of its components; ablations would follow only if it works. Houston18 GT has already informed this choice, so this is exploratory.

Baseline A is the existing source-val-best CE-only run at seeds 202601/202602/202603. New arm SHIFT uses identical DCRN initialization, official ILDA cache, Houston13→Houston18 source split (180/class), official 53,200 target centers/order, 7×7 patches, batch size 32, 38 updates/epoch, 100 epochs, official six forward passes, official radiation noise/flip, SGD `lr=.01/(1+10*(epoch-1)/100)^.75`, momentum .9 and decay 5e-4 with optimizer reset each epoch, and earliest source-val-best checkpoint. Target GT enters only official center selection during training. No target class label, pseudo-label, HyperSIGMA teacher, OT, or Flow enters the loss.

After the six official passes, add one **train-mode, BN-updating** source auxiliary pass. Calculate full-cube post-ILDA per-band source/target mean and population std without using labels. Historical source→target style interpolation uses `alpha=0.7`, `eps=1e-5`, per-patch multiplicative `1+0.04*N(0,1)`, `0.015*avg_pool5(N(0,1))` noise, and `clamp(0,1)`. Its random generator is separate so the official loader and augmentation RNG trajectory is preserved. Train with `CE(original source)+0.5*CE(shifted source)`. This is a *single composite intervention* borrowed from the clean DCRN historical record, not a search over alpha/loss/BN choices.

First run a five-epoch technical smoke at seed 202601 and verify 190 source/target input and CPU RNG hashes against A; compare CUDA RNG hashes against the matched F1 smoke, which has the same initial DCRN and six-pass scaffold. The existing A run initializes an additional unused EMA teacher and has a different CUDA RNG state from F1 even before this intervention; the SHIFT smoke matches F1's CUDA hashes at all 190 steps. This clarification was recorded before formal training or target-GT scoring. Do not score target in smoke. If finite and matched, run full three-seed 100-epoch grid without changing constants. Freeze raw target probabilities for all three source-val-best checkpoints before any new GT scoring, then apply the already fixed HyperSIGMA-prior soft-KL `lambda=1` only as a secondary comparator. Score official OA (`correct/53,200`), AA/Kappa (53,184), all class recalls, especially class 6/7, mass and candidate quality. Keep the primary raw result visible. A positive Houston18 result requires independent-seed/scene confirmation before a method claim. Flow remains off in this experiment.
