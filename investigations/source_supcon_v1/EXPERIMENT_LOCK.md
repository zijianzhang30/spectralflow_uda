# Source-discriminative F1 pilot, frozen before target scoring

Question: can source-label class separation stabilize the target decision boundary moved by F1's target feature consistency? This is an exploratory hypothesis informed by the completed F1/F2 target-label diagnosis; it is **not** an independent Houston18 validation.

Intervention F1S: start from exactly the F1 training process and add `0.1 * L_supcon` on the **existing clean source 288-dimensional features**, with normalized cosine logits and temperature `0.1`. Positive pairs are all other source-batch samples with the same true source label. Self-pairs are excluded; anchors with no positive are omitted. This loss is symmetric across all seven classes. No target pseudo-labels, class-specific weights, new augmentation, extra forward pass, HyperSIGMA gradient, OT, or Flow. The fixed `0.1` weight and temperature are implementation choices for this pilot, not selected on target GT; this pilot must report sensitivity as a limitation rather than retrospectively tuning them.

Keep Houston13→Houston18, official ILDA cache, 180/class source split, 53,200 official target centers/order, patch 7×7, batch 32, 38 updates/epoch, official noise/flip passes, optimizer and LR horizon, 100 epochs, and source-val-best checkpoint rule. A five-epoch technical smoke run at seed 202601 may check finite gradients, positive-pair counts, identical source/target input hashes to F1 and healthy source validation, but **must not read target GT for performance or select a variant**. The smoke run does not constitute evidence of target improvement.

After smoke passes, train full 100-epoch F1S runs paired to A/F1 for seeds 202601/202602/202603 without changing constants. Preserve checkpoints and probabilities before target-GT scoring. Evaluate raw and the pre-existing HyperSIGMA-prior soft-KL lambda=1 corrected predictions under the same 53,184/53,200 official metric rule. Report OA, AA, Kappa, seven class recalls, per-class soft mass, and correspondence diagnostics. Because the current scene has informed this idea, any apparent gain requires new seeds or another scene before it can be claimed as generalization. Flow stays out of this experiment.
